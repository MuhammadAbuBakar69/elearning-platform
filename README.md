# E-Learning Platform Starter Code

An interactive course portal and lesson progress tracker built with React.

## Features
- **Course Catalog**: Filterable course cards showing instructor, category, lessons count, and progress bar.
- **Detailed Course View**: View course lessons, video player preview, and module checklist.
- **Interactive Checklist**: Mark individual lessons complete/incomplete with instant progress sync.
- **Global & Course Stats**: Calculates total learning progress percentage dynamically.
- **LocalStorage Persistence**: Stores completed lesson states across sessions.
